Git 커밋 및 푸시 명령어서

Git 커밋 및 푸시 명령어 순서

1. 현재 작업 디렉토리로 이동
cd /workspace/git_project/yawooch/projects/privateProject/spring/Pensieve
2. 현재 Git 상태 확인
git status
3. 변경된 파일들을 스테이징 영역에 추가
• 특정 파일만 추가
git add src/main/webapp/WEB-INF/views/memoryCard.jsp
git add src/main/webapp/resources/js/memo.js
• 또는 모든 변경사항을 한번에 추가
git add .
4. 커밋 메시지와 함께 커밋
git commit -m "feat: 메모리 카드 컴포넌트 Toastui Editor viewer로 표시하도록 수정" - memoryCard.jsp: 100% 미만 컨텐츠를 Toastui Editor viewer로 표시
- memo.js: Toastui Editor 초기화 및 뷰어 설정 업데이트
- 컨텐츠 편집과 방식 자연 웹 미디어는 처리"
